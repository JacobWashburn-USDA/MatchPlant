Getting Started

There are two ways to work through the MatchPlant pipeline. Pick whichever fits how you like to work.

1

Use this dashboard

A web page that walks you through MatchPlant step by step. Click a module to see what it needs, fix anything missing with one click, and run it right there.

2

Follow the GitHub README

Read the documentation and run each module's script yourself from a terminal.

Using the dashboard

Please follow the steps below to get started.

Everything runs on your own computer's hardware, not a remote server:

  • GPS embedding, GCP marking, annotation, and image splitting run fine on a normal laptop.
  • For OpenDroneMap (orthomosaic generation) and training or testing the detection model, a GPU is recommended for higher-quality results and faster processing, along with at least 16 GB of RAM. Free disk space needed depends on the size of your UAV image dataset.
