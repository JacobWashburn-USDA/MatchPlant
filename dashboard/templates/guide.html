How to Use

Choose a module, provide its inputs, and check its output. This guide explains how to run a step and move to the next one when you are ready.

Run a module

  1. 1

    Choose the step you need

    Open the dashboard home and select a module card. The 11 modules are grouped into four stages; the pipeline flow shows how they connect. You can start at a later step if you already have its required inputs.

    Choose a module
  2. 2

    Read the instructions and prepare your inputs

    On the module page, open README instructions before running. Check which images, annotations, model files, or other inputs it needs, and where it saves its results.

  3. 3

    Install requirements, if needed

    If the page reports missing or incompatible packages, select Install requirements and wait for installation to finish successfully in the Output panel. The dashboard creates a Python environment for that module and selects it automatically. For ODM Runner, also check that Docker Desktop is installed and running.

  4. 4

    Provide inputs and start the module

    For a form or training module, select files and folders with Choose file or Choose folder, review the settings, then select Run. Help icons explain each field; optional blank fields use the displayed defaults.

    For a desktop app, select Launch, then choose inputs and start processing in the separate app window. The dashboard Output panel shows process messages and errors.

  5. 5

    Check the results, then choose your next step

    Wait for processing to finish and check the saved results described in the module's README. If an error appears, resolve it before using those results in another module.

    Return to the dashboard home and choose the next module you need. Select the previous step's saved files or folders as its inputs. The dashboard does not automatically pass results between modules or run the whole pipeline.

    You do not need to run every module. Skip a step when you already have the inputs needed for the next one. Choose 6-1 Object Detection Trainer or 6-2 Transfer Learning as your training route; both can provide a model for 7 Object Detection Tester.

    Choose your next module

Your computer and prerequisites

Modules run on the computer hosting this dashboard. Processing time, memory, and disk space depend on your dataset and settings.

  • Desktop apps: their windows open on that computer, so run the dashboard locally when using them.
  • ODM Runner: requires Docker Desktop in addition to the module's Python packages.
  • Training and testing: check the module README for dataset, model, and device settings before starting a long run.
  • While working: keep the MatchPlant Dashboard server window open. Closing it stops the dashboard.

Useful controls

  • Dependency status. Each module page indicates whether its required package versions are installed, checked automatically against that module's own requirements*.txt. If anything is missing, Install requirements creates a dedicated environment for that module and configures the dashboard to use it.
  • Output and Stop. Launch, Run, and Install requirements stream process messages to the Output panel. Stop cancels an active process. Use View log to inspect a recent run while the dashboard server is still running. Only one process per module runs at a time.
  • Source code. Each module page links to its folder, README, script, and requirements file on GitHub, so the underlying code can be reviewed before running it.
  • Pipeline flow. Follow the connections on the homepage to find the next relevant step. For example, Image Splitter prepares datasets for a training route, and Object Detection Tester evaluates the resulting model.
  • Custom environments. The Settings page allows a module to be pointed at an existing Python environment instead of a newly created one. This is only needed if a compatible environment (for example, an existing PyTorch or GDAL setup) already exists.
